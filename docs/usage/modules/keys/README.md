# KEYS tab: piano roll, MIDI, and chord/melody generators

**In one line:** play and write melodies using a pad's sound at different pitches.

## What this part of the plugin is for

The KEYS tab turns the selected pad into a playable instrument. There's a
keyboard on the left, and on the right a grid where up and down is pitch and
left to right is time (a "piano roll"). It edits the same pattern as the SEQ
tab, just with pitch and note length added. You can also save a pattern as a
MIDI file for your DAW, load a MIDI file in, or have the plugin write chords
and melodies in a key you choose.

## What's in this folder

| File | What you'll learn |
|---|---|
| [keys-tab.md](keys-tab.md) | Auditioning a pad at different pitches, placing and resizing notes, **Export MIDI / Import MIDI**, **Chords...** (a progression spread across several pads), **Melody...** (a tune on one pad, optionally following your chords), and **Generate...** (1-bar preview-then-commit, or 4 bars written straight into all banks as an arrangement) |

## Questions this answers

- *How do I play a melody with a vocal chop?* Select its pad, then click or drag along the keyboard.
- *How do I get this pattern into my DAW's piano roll?* Use **Export MIDI...** and drag the file in.
- *Can it write chords for me?* Load the same sustained sound onto a few pads, then use **Chords...**.
- *What does "Commit" do?* A 1-bar Generate only previews until you click Commit.

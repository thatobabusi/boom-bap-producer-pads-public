# DISCOVER tab: digging for new material

**In one line:** a crate for finding sounds, from your own folders and from YouTube videos you've tagged.

## What this part of the plugin is for

"Digging" is how producers find things to sample. This tab gives you two
crates. **Local Files** is a shuffle-and-listen browser over your own audio
and video files: point it at a folder and new files show up automatically,
and an audio file you like can go straight onto a pad. **YouTube Crate** lets
you watch YouTube videos inside the plugin, tag them (genre, key, BPM,
year...), filter your collection, and get "up next" suggestions that fit what
you're listening to. **Nothing is ever downloaded**: local files are only
played, and YouTube videos are only embedded, the way any website shows them.

## Questions this answers

- *Can it download audio from YouTube?* No, by design. It only embeds the video.
- *Why does YouTube search need a "proxy"?* Searching needs a Google key, and a key inside an installed program could be stolen. A small relay service keeps it safe. Watching by pasting a link works without one.
- *How do I get a sound from my downloads onto a pad?* Set that folder as the Watch Folder, pick the file, and use **Load to Pad**.

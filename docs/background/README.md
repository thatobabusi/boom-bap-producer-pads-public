# Background reading

Context that isn't needed to *use* the plugin, but helps make sense of it.
It explains the words and history behind music software, for anyone who
wants to know why things are the way they are.

## The short version

A *plugin* is a small program that runs inside your music software (your
DAW: FL Studio, Ableton, Reason and so on). A *plugin format* is the agreed
"plug shape" that lets any plugin fit into any DAW. **VST3** is the
mainstream format on Windows today, so it's what this plugin is built for
first. **CLAP** is a newer, open format with some modern extras; it's
offered too, for DAWs that support it (Bitwig, for example). The old
**VST2** format has been retired (Steinberg stopped licensing it to new
developers), and VST3 already works in every DAW this plugin targets, so
there's no VST2 version. The installer and download options are covered in
[INSTALL.md](../INSTALL.md).
